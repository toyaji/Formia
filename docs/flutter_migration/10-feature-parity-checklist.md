# 10 — 기능 동등성 체크리스트 (레거시 vs 신규 스택)

Phase 7(`05-migration-plan.md`) DoD: "기능 동등성 체크리스트 통과 후 레거시 제거". 이 문서는 레거시(`src/`, `prisma/`,
`src-tauri/`, Next.js)의 실제 기능을 하나씩 신규 스택(Flutter `apps/editor` + Jaspr `apps/public_form` + Supabase)과
대조한 것 — 코드를 직접 읽고 확인함(문서 추정이 아님).

> **레거시 삭제는 이 문서 통과만으로 자동 진행하지 않는다.** 사용자 방침(2026-07-06): 디자인이 레거시와 "누가 봐도
> 비슷하다" 수준으로 확인된 시점에 사용자의 최종 검사를 받고 나서 삭제한다. 이 체크리스트는 그 판단을 위한 "기능" 축
> 자료이고, "디자인/시각적 동등성"은 별도로 사용자가 직접 대조한다.

범례: ✅ 동등 이상 · ⚠️ 부분/변경됨(의도적 스코프 조정 포함) · ❌ 아직 없음(회귀 또는 미구현)

## 인증 · 대시보드

| 기능 | 레거시(`src/`) | 신규(`apps/editor`) | 상태 |
| --- | --- | --- | --- |
| Google OAuth 로그인 | NextAuth | Supabase Auth (Google) | ✅ |
| Google One Tap (`GoogleOneTap.tsx`) | 있음 | 없음 | ❌ (사소, 후속 검토) |
| 게스트 모드 + 로컬 임시저장 | IndexedDB(Zustand persist) | Hive(웹 IndexedDB·데스크톱은 로컬 파일) | ✅ |
| 폼 목록/생성/삭제 | ✅ | ✅ | ✅ |
| **`.formia` JSON 가져오기/내보내기**(대시보드 드래그앤드롭, `dashboard/page.tsx` `importForm`/`exportFormById`) | ✅ | **없음**(`apps/editor/lib/ui/dashboard/dashboard_page.dart`에 관련 코드 없음, 직접 확인) | ❌ **회귀 — Phase7 잔여 작업 필요** |
| 게스트 복원 프롬프트 | 없음(자동 persist라 프롬프트 개념 자체가 없음) | 있음(`restore_draft_prompt.dart`) | ✅ 개선 |

## 종합

- **레거시 삭제 전 반드시 메워야 할 진짜 회귀 2건**:
  1. 대시보드 `.formia` 가져오기/내보내기 (모든 계층에서 확인, 사용자가 매일 쓰던 기능일 가능성 있음 — 우선순위 높음)
  2. 공개 폼 다중 페이지 순차 네비게이션 (현재 신규는 한 페이지 몰아서 렌더 — 폼이 길면 사용자 경험 차이가 큼)
- **의도된 축소(레거시 삭제를 막을 이유는 아님, 다만 사용자 인지 필요)**: OpenAI BYOK 미지원, 로그인 Vault 키 경로 미구현, 채팅 이력 휘발성, Google One Tap 없음.
- **레거시에도 원래 없던 것(신규 미구현이어도 "회귀 아님")**: 조건부 분기 UI, 완료율/이탈 분석, 데스크톱 네이티브 파일 저장, 제출 레이트리밋(레거시는 없었음 → 신규가 오히려 더 안전).
- **신규가 레거시보다 명백히 나은 것**: 응답 열람 대시보드, CSV 내보내기, undo/redo(레거시는 사실상 죽은 코드였음), 제출 레이트리밋/봇 차단, SSR 시맨틱 마크업.
